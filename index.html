制度ずかん Uploader

A private tool for the YouTube channel "制度ずかん" (Seido Zukan)

概要 / About

「制度ずかん Uploader」は、YouTubeチャンネル「制度ずかん」の運営者が、自分で制作した制度解説動画を自分のチャンネルにアップロードし、自分のチャンネルの再生統計を確認するための個人用ツールです。運営者本人のみが利用し、第三者のアカウントにはアクセスしません。

"Seido Zukan Uploader" is a personal tool used only by the operator of the YouTube channel "制度ずかん". It uploads videos that the operator produced to the operator's own channel and reads the operator's own channel statistics. It does not access any other user's account.

使用する Google API / Google APIs used

  • YouTube Data API v3 — 自チャンネルへの動画アップロード、自チャンネルの動画情報・公開統計の取得 / uploading videos to and reading public statistics of the operator's own channel
  • YouTube Analytics API — 自チャンネルの視聴データ(再生回数・平均視聴時間など)の取得 / reading the operator's own channel analytics
