1. 本ツールについて / About this tool

制度ずかん Uploader(以下「本ツール」)は、YouTubeチャンネル「制度ずかん」の運営者本人のみが、自分のパソコン上で使用する個人用ツールです。一般の利用者向けに提供するものではありません。

This tool is used only by the operator of the YouTube channel "制度ずかん", on the operator's own computer. It is not offered to the public.

本ツールは YouTube API Services を使用します。本ツールの利用には YouTube 利用規約 (YouTube Terms of Service) が適用され、Google によるデータの取り扱いには Google プライバシーポリシー (Google Privacy Policy) が適用されます。

This tool uses YouTube API Services. By using it, the user agrees to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.

2. アクセスする情報 / Information accessed

本ツールは、運営者本人が OAuth で許可した範囲で、運営者自身の YouTube チャンネルの次の情報にのみアクセスします。

  • チャンネル情報(チャンネルID・名称)/ channel ID and name
  • 自チャンネルの動画の情報(タイトル・公開日時・公開状態)と公開統計(再生回数・高評価数・コメント数)/ own videos' metadata and public statistics
  • YouTube Analytics の集計値(再生回数・総再生時間・平均視聴時間・平均視聴率・登録者増減)/ aggregated analytics of the own channel

また、運営者が制作した動画ファイルとそのタイトル・説明・タグ・サムネイルを、運営者のチャンネルにアップロードします。

本ツールは、他のユーザーのアカウント情報、視聴者の個人情報、コメント本文にはアクセスしません。急上昇動画や検索結果など、YouTube 上で一般に公開されている動画の統計を、傾向の把握のために取得することがあります。

The tool does not access other users' accounts, viewers' personal information, or comment text. It may read public statistics of publicly available videos (e.g. trending or search results) to understand trends.

3. 利用目的 / How the information is used

  • 運営者が制作した動画を自チャンネルへアップロード・公開予約するため / to upload and schedule the operator's own videos
  • 自チャンネルの成績を分析し、今後の動画のテーマや公開時刻を改善するため / to analyze the channel's own performance and improve future videos

4. 第三者への提供 / Sharing with third parties

取得した情報を販売したり、広告目的で第三者に提供したりすることはありません。

ただし、分析のために、自チャンネルの動画タイトルと集計値(再生回数・平均視聴率など、個人を特定しない数値)、および公開動画の統計を、AI サービス Anthropic Claude に送信して処理することがあります。視聴者の個人情報は送信しません。Anthropic によるデータの取り扱いは Anthropic のプライバシーポリシー に従います。

We do not sell or share the information for advertising. For analysis, the titles of the operator's own videos, aggregated non-personal statistics, and public statistics of public videos may be processed by the AI service Anthropic Claude. No viewer personal information is sent. See Anthropic's Privacy Policy.

5. 保存と削除 / Storage and deletion

OAuth の認証情報(アクセストークン・リフレッシュトークン)と取得した統計は、運営者のパソコン内のファイルにのみ保存され、外部のサーバーには保存しません。統計データは分析に必要な期間保存し、不要になったものは削除します。

OAuth tokens and retrieved statistics are stored only in local files on the operator's computer and are not stored on any external server. Statistics are kept as long as needed for analysis and deleted when no longer needed.

YouTube 上の一般公開動画から取得した統計は、取得から30日以内に自動で削除します。自チャンネルの統計も、アクセス許可を取り消した場合は30日以内に削除します。保存されている情報の削除は、下記の連絡先へのメールでも依頼できます。

Statistics of public videos obtained from YouTube are automatically deleted within 30 days of retrieval. If access is revoked, the stored data of the own channel is also deleted within 30 days. Deletion of stored data can also be requested by email to the contact below.

本ツールへのアクセス許可は、Google アカウントのセキュリティ設定ページ からいつでも取り消せます。取り消しと同時に、パソコン内の認証情報ファイルも削除します。

Access can be revoked at any time via the Google security settings page; the local token file is deleted at the same time.

6. Cookie 等 / Cookies

本ツールはパソコン上で動作するプログラムであり、Cookie やトラッキング技術は使用しません。このウェブページもアクセス解析を行っていません。

The tool is a local program and does not use cookies or tracking. This web page does not use analytics.

7. 変更 / Changes

本ポリシーを変更する場合は、このページを更新し、最終更新日を改めます。
